# Models

This folder is reserved for optional risk-modelling work after the analytical platform is complete.

The project will not begin with machine learning. The priority is to establish reliable data generation, dimensional modelling, SQL analytics, KPI definitions and data-quality controls first.

If a model is added later, it may cover fraud-risk scoring or anomaly prioritisation and will include validation, class-imbalance handling, explainability and limitations rather than presenting accuracy alone.
