# Metric Definitions

This document defines the initial semantic/KPI layer for the project. Metrics may be refined after the synthetic generator and warehouse are implemented, but any change should be documented here so dashboard calculations remain consistent.

## Core Payment Metrics

| Metric | Definition |
|---|---|
| Transaction Volume | Count of all transaction records in scope |
| Transaction Value | Sum of `transaction_amount` for transactions in scope |
| Approved Transactions | Count of transactions where `transaction_status = 'Approved'` |
| Declined Transactions | Count of transactions where `transaction_status = 'Declined'` |
| Approval Rate | Approved Transactions / Transaction Volume |
| Decline Rate | Declined Transactions / Transaction Volume |
| Approved Payment Value | Sum of `transaction_amount` for approved transactions |
| Average Transaction Value | Transaction Value / Transaction Volume |

## Risk Metrics

| Metric | Definition |
|---|---|
| Fraud Transactions | Count of transactions where `is_fraud = TRUE` |
| Fraud Transaction Rate | Fraud Transactions / Transaction Volume |
| Fraud Loss | Sum of `fraud_loss_amount` |
| Fraud Loss Rate | Fraud Loss / Approved Payment Value |
| Cross-Border Transactions | Count where `is_cross_border = TRUE` |
| Cross-Border Transaction Rate | Cross-Border Transactions / Transaction Volume |

## Customer Metrics

| Metric | Definition |
|---|---|
| Active Customers | Distinct customers with at least one transaction in scope |
| Transactions per Customer | Transaction Volume / Active Customers |
| Payment Value per Customer | Transaction Value / Active Customers |
| Approved Value per Customer | Approved Payment Value / Active Customers |

## Merchant Metrics

| Metric | Definition |
|---|---|
| Active Merchants | Distinct merchants with at least one transaction in scope |
| Merchant Transaction Volume | Transaction count grouped by merchant |
| Merchant Approved Value | Approved Payment Value grouped by merchant |
| Merchant Approval Rate | Approved merchant transactions / total merchant transactions |
| Merchant Fraud Rate | Fraud merchant transactions / total merchant transactions |

## Operational Metrics

| Metric | Definition |
|---|---|
| Average Processing Time | Average `processing_time_ms` for transactions in scope |
| P95 Processing Time | 95th percentile of `processing_time_ms` |
| Decline Reason Share | Transactions for a decline reason / total declined transactions |

## Calculation Principles

1. Every dashboard measure should have one documented business definition.
2. Numerator and denominator filters must use the same reporting scope unless explicitly stated.
3. Rates should guard against division by zero.
4. Currency aggregation across markets will not be presented as a comparable global monetary total until a documented common-currency conversion approach is implemented.
5. Fraud metrics refer only to synthetic confirmed fraud labels generated by this project; they do not represent real-world fraud prevalence.
6. Dashboard labels should distinguish transaction counts, local-currency values and any later normalised value measures.
